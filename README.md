# AHK RP Scripts — SAMP / CRMP 
[Перейти](https://qupinator.github.io/ahk/)

Генератор AHK-скриптов для ролевых отыгровок в SA:MP и CRMP. Настройте команды, нажмите кнопку — получите готовый код для AutoHotkey v1.1.

## Что умеет

- **Генератор** — собирайте последовательность команд (`/me`, `/do`, `/try`, `/todo`, `/s`, `/r`, `/d` или свою) с настраиваемыми задержками между ними.
- **Клавиши** — выбор клавиши запуска (F1–F8, Numpad, Ctrl/Alt-комбо через «Другая…») и клавиши чата (F6, T или своя).
- **Авто-смена раскладки** — скрипт сам переключит раскладку перед отправкой команд в чат.
- **Задержки** — общая для всех команд или индивидуальная для каждой пары.
- **Шаблоны** — быстрые заготовки (осмотр документов, проверка паспорта, досмотр авто, рация патруля) — загружаются в генератор одной кнопкой.
- **Готовые скрипты** — сразу копировать или скачать `.ahk`, без генератора.
- **Удобства** — перетаскивание команд (drag&drop), копирование в буфер, скачивание файла с любым именем, автосохранение настроек в браузере, отмена очистки в течение 10 секунд.

## Как пользоваться

1. Скачайте и установите [AutoHotkey](https://www.autohotkey.com/), если его нет.
2. Откройте сайт, добавьте команды и выберите клавиши.
3. Нажмите **Сгенерировать** — код появится в блоке ниже.
4. Скопируйте код или скачайте файл `.ahk`.
5. Запустите файл двойным кликом — скрипт появится в трее Windows.
6. В игре нажмите выбранную клавишу запуска (по умолчанию **Num2**).

## Полезно знать

- Сгенерированный код можно править вручную прямо в блоке — но после изменения настроек появится метка «Устарело».
- Скрипт останавливается кнопкой `Return` — на одну команду одна клавиша.
- Данные хранятся только локально в вашем браузере (`localStorage`), никуда не отправляются.

*Для использования в играх соблюдайте правила сервера — на некоторых проектах автосенд-скрипты запрещены.*
